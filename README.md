## 项目简介

软件、社区、论坛……不同平台有不同的密码要求。长度、符号、大小写各有规则，密码越设越多，忘记的次数也越来越多。

**我的密码本**希望让你只需记住一个主密码，就能统一管理各个平台的密码，减少记忆和查找密码的负担。

项目目前处于 **Beta 开发阶段**，正在逐步完善基础能力，下列功能为后续开发规划。

## 下载安装

前往 **[Releases 页面](../../releases)** 查看已发布版本及更新说明。版本发布后，可在对应版本的附件中下载 APK 安装包。

支持 **Android 9.0 及以上版本**。

## 开发计划

- [ ] **密码管理**：统一保存、查看、编辑和查找各个平台的账号密码。
- [ ] **加密存储**：使用主密码保护密码数据，实现本地加密存储。
- [ ] **云端备份**：支持密码数据的云端备份与恢复。
- [ ] **主题切换**：支持浅色、深色主题，适配不同使用习惯。
